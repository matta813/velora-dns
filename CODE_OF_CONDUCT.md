# Code of Conduct

Be respectful, constructive, and welcoming. Critique ideas, not people. Harassment,
discrimination, threats, and disclosure of private information are unacceptable.
Respect different backgrounds and experience levels.

Maintainers may edit or remove harmful contributions and restrict participation.
Report misconduct privately through the repository owner's GitHub profile contact
options; if unavailable, request a private contact without exposing personal details.
Maintainers will handle reports confidentially and fairly.
